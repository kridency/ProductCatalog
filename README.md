# Marketplace

## Описание

Серверная часть приложения продуктового каталога.

## Предпосылки

Среда выполнения содержит пакеты: 

- Java SE 17;
- сборщик пакетов Apache Maven.

Все команды запускаются в консоли из папки проекта ``ProductCatalog/``.

Первоначальные настройки отсутствуют.

## Сборка

Перед cборкой проекта потребуется запуск Docker образа с СУБД PostgreSQL в качестве резидента, который производится командой:
``docker compose --project-directory ./docker/ up --detach``. 

Сборка проекта производится командой ``mvn clean package``. При успешном завершении результаты сборки будут расположены в папке ``target/``

## Запуск

Для запуска приложения необходимо выполнить команду ``java -cp bin:./target/* org.example.productcatalog.ProductCatalogApplication``

## Инструкции по использованию

Использование функциональности приложения производится посредством перехода по сетевой ссылке <http://localhost:8080<endpoint>>, где <endpoint\> представляет отдельную API команду.
Приложение использует базовую аутентификацию, при этом в качестве ``Username`` указывается адрес электронной почты пользователя.

Приложение подразумевает выполнение следующих API команд:

### Команды сервиса <span style="color: lightgreen">${auth}$</span>

- <span style="color: lightblue">${/api/v1/auth/create}$</span> - вызов команды производится с помощью HTTP метода `POST`. Команда ожидает входные данные в виде объекта в `JSON` нотации `{ "email": <адрес электронной почты>, "password": <пароль> }`. Результатом успешного выполнения данной команды является создание новой учетной записи;
- <span style="color: lightblue">${/api/v1/auth/login}$</span> - вызов команды производится с помощью HTTP метода `POST`. Команда ожидает входные данные в виде объекта в `JSON` нотации `{ "email": <адрес электронной почты>, "password": <пароль> }`. Результатом успешного выполнения данной команды является аутентификация пользователя;

### Команды сервиса <span style="color: lightgreen">${identity}$</span>

- <span style="color: lightblue">${/api/v1/identity/logout}$</span> - вызов команды производится с помощью HTTP метода `DELETE`. Результатом успешного выполнения данной команды является удаление учетной записи пользователя и завершение текущей сессии;
- <span style="color: lightblue">${/api/v1/identity/update}$</span> - вызов команды производится с помощью HTTP метода `PUT`. Команда ожидает входные данные в виде объекта в `JSON` нотации `{ "email": <адрес электронной почты>, "password": <пароль> }`. Результатом успешного выполнения данной команды является обновление пароля учетной записи пользователя текущей сессии;

### Команды сервиса <span style="color: lightgreen">${administration}$</span>

- <span style="color: lightblue">${/api/v1/administration/list}$</span> - вызов команды производится с помощью HTTP метода `GET`. Команда ожидает входные данные в виде объекта в `JSON` нотации `{ "email": <адрес электронной почты>, "password": <пароль> }`. Результатом успешного выполнения данной команды является возврат перечня пользователей, удовлетворяющего критериям указанным в виде `JSON` нотации;

### Команды сервиса <span style="color: lightgreen">${product}$</span>

- <span style="color: lightblue">${/api/v1/product/create}$</span> - вызов команды производится с помощью HTTP метода `POST`. Команда ожидает входные данные в виде объекта в `JSON` нотации `{ "item": <артикул>, "brand": <товарная марка>, "title": <наименование>, "category": <категория>, "price": <цена> }`. Результатом успешного выполнения данной команды является создание новой записи товара;
- <span style="color: lightblue">${/api/v1/product/list}$</span> - вызов команды производится с помощью HTTP метода `GET`. Команда ожидает входные данные в виде объекта в `JSON` нотации `{ "item": <артикул>, "brand": <товарная марка>, "title": <наименование>, "category": <категория>, "price": <цена> }`. Результатом успешного выполнения данной команды является возврат перечня товаров, соответствующих шаблону указанному в теле запроса.
- <span style="color: lightblue">${/api/v1/product/update}$</span> - вызов команды производится с помощью HTTP метода `PUT`. Команда ожидает входные данные в виде объекта в `JSON` нотации `{ "item": <артикул>, "brand": <товарная марка>, "title": <наименование>, "category": <категория>, "price": <цена> }`. Результатом успешного выполнения данной команды является обновление записи товара, исходя из существующего артикула;
- <span style="color: lightblue">${/api/v1/product/delete}$</span> - вызов команды производится с помощью HTTP метода `DELETE`. Команда ожидает входные данные в виде объекта в `JSON` нотации `{ "item": <артикул>, "brand": <товарная марка>, "title": <наименование>, "category": <категория>, "price": <цена> }`. Результатом успешного выполнения данной команды является удаление записи транзакции, исходя из существующего артикула;
